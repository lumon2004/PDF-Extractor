# PDF Extractor

A simple Python CLI to extract selected pages from a PDF file.

## Features
- Interactive PDF file selection
- Tab-completion for file paths
- Select single pages, ranges, or mixed combinations
- Save extracted pages as a new PDF

## Installation

```bash
git clone https://github.com/lumon2004/PDF-Extractor.git
cd PDF-Extractor
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
# .venv\Scripts\activate  # Windows
pip install -r requirements.txt
